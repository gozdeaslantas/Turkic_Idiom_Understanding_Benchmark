# Multilingual Idiom Semantic Benchmark 

This repository accompanies a submission to SIGTURK / ACL 2026.

We release:
- Experiment scripts and evaluation code
- Dataset split files
- Exact configuration and hyperparameter settings

To preserve double-blind integrity, **model checkpoints are referenced but not mirrored in this repository**.
All resources are hosted on HuggingFace and will be made public soon.
